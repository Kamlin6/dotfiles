# ~/bin/utils — 系统架构

## 管线总览

```
┌────────────────────────────────────────────────────────────────┐
│                        录入管线                               │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  Audio ──→ transcribe ──→ text / srt / segments.json          │
│              (ASR)                                             │
│                                                                │
│  Audio + SRT ──→ srt-slice ──→ sliced_wavs + manifest.json    │
│                    (切片)      → GPT-SoVITS 数据预处理产出    │
│                                                                │
│  Image / PDF ──→ ocr ──→ text / json                           │
│                   (OCR)                                        │
│                                                                │
└────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌────────────────────────────────────────────────────────────────┐
│                        合成管线                               │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  sliced_wavs + ref ──→ GPT-SoVITS ──→ synthetic_wavs          │
│  manifest.json         (TTS + LoRA)                            │
│                                                                │
└────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌────────────────────────────────────────────────────────────────┐
│                        评估管线                               │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  synthetic_wavs + ref_wavs ──→ tts-eval ──→ report.json       │
│                                   (WER/CER + DNSMOS)          │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

## 模型依赖

| 工具 | 依赖模型 |
|------|---------|
| `transcribe` | FasterWhisper（CTranslate2 格式） |
| `tts-eval` | openai-whisper + speechmos (DNSMOS) |
| `ocr` | PaddleOCR ONNX（ch_PP-OCRv4, ~/models/ocr/） |
| `download_sepformer_models.sh.code.bash` | SepFormer（语音分离） |

模型文件统一存放在 `~/models/`。

## 目录约定

- 工具脚本 → `~/bin/utils/`（$PATH 已含）
- 模型权重 → `~/models/<model-name>/`
- 工程文档 → `~/bin/utils/PIPELINE/`（Lite 流程）

## 设计原则

- **管道式**：每条管线输出 = 下一条管线的输入，中间产物明确
- **单步可独立跑**：录入/合成/评估每一步可单独执行，不依赖上下游
- **纯 CLI**：无 web UI，标准输入/输出/文件
- **零外部服务**：全部本地执行，不依赖云 API
